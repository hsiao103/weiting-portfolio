# WEITING HSIAO｜個人作品集

這是蕭維霆的個人作品集網站，整理教育、設計與科技整合的實作成果。

## 線上入口

- [作品集首頁](https://hsiao103.github.io/weiting-portfolio/)
- [作品專題與分類](https://hsiao103.github.io/weiting-portfolio/works.html)
- [作品集目錄 Markdown](作品集目錄.md)

## 作品集架構

### 第一層：首頁

首頁以三個主要方向建立快速入口：

1. 數位學習
2. 藝術與創客
3. 課程與校務領導

### 第二層：作品專題

第二層依成果性質整理代表作品，包含公開網站、互動作品與持續整理中的專題。公開作品會連結至各自的正式網站，維持原有程式、素材與資料運作。

## 檔案說明

## 維護方式

本儲存庫負責作品集入口與內容索引；各互動作品仍維持在原本的 GitHub Pages 專案中，避免搬移相依資源後造成程式、圖片、題庫或設定失效。
